# LexiReview

AI-assisted legal document review — single-document analysis with verified, citation-backed
findings and mandatory human review. See `docs/` for the PRD (v2.4.1) and decision log.

**New here? Read `SETUP_GUIDE.md` — it takes you from zero to a running stack, step by step.**

Quick start: `cp .env.example .env` (fill in your key) → `docker compose up --build`
→ http://localhost:8000/health
